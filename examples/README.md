# 作品档案

按「原始照片 → 最终 X 光图」保存代表案例，每个案例一个子目录。

## 案例

- `case-1-fullbody/` — 单人全身照：完整骨骼 + 半透明衣物
- `case-2-overhead/` — 俯视骷髅：蓝白边缘光 + 发丝

## 目录结构

```
examples/
└── <案例名>/
    ├── source.jpg     # 原始照片
    └── result.png     # X 光结果
```

## 建议补充的场景

- 多人合照
- 环境照 / 随手拍（分层背景）
- 带手持物的人物（手机/包）
- 非人物（宠物/植物/物品）
